# axcpt
A recreation of the AX-CPT for a project! A cognitive test that runs for approximately 2 minutes, where the goal is to press the spacebar on every letter that ISN'T an X.

Built mostly in Javascript and HTML, so it's hosted on Github Pages and functions mostly on strings. It's mainly made to emulate the actual test (AX-CPT), but I couldn't find the source code to try and recreate it exactly, so it's just reverse-engineered as well as I could...

As for why it's so boring - that's how the original test is! This is designed to minimize distractions (as this is based off a screening for ADHD) and it's a gauge for reflexes/testing.
